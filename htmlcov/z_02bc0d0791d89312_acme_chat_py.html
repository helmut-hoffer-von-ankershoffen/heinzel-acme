1"""`acme-chat`: a fictional command-line chat tool that tells the user something or asks them, as JSON. 

2 

3It stands in for a company's own chat command, so the chat adapter of heinzel-acme-connectors can show how to drive 

4one: an argument list, no shell, a timeout and a bounded JSON answer. It talks to nobody. Answers to questions come 

5from a fixture: 

6 

7- `ACME_CHAT_ANSWER`: one JSON object used for every question, `{"choice": "Yes"}` or `{"reply": "text"}`; 

8- `ACME_CHAT_ANSWERS`: the path of a JSON file mapping a word in the question to such an object. 

9 

10Without an answer it waits `--wait-seconds`, at most `ACME_CHAT_MAX_WAIT` seconds (0 unless set, so it never 

11blocks for real), and reports that the wait ran out. Usage: 

12 

13 acme-chat tell TEXT [--topic ID] [--note TEXT] 

14 acme-chat question TEXT [--choice A --choice B ...] [--wait-seconds N] [--topic ID] [--note TEXT] 

15 

16Both print one JSON object: `{"message": ID, "topic": ID}`, plus for a question `"choice"`, `"reply"` or 

17`"expired": true`. Exit 2 for wrong usage or an answer that isn't one of the choices. 

18"""
